# รวม Red Flags ทุกสัญญา (ฉบับจำง่าย)

> ไฟล์นี้รวม “สัญญาณอันตราย” จากทุกประเภทสัญญาไว้ที่เดียว
> เจอข้อไหน = ให้ฉุกคิด ถามให้ชัด หรือขอแก้สัญญาก่อนเซ็น

---

## ⚡ TOP สัญญาณอันตราย เจอเมื่อไหร่ให้หยุดคิดทันที

- ไม่ยอมจ่ายมัดจำ / ให้ทำงานก่อนโดยไม่มีเอกสาร
- ขอ source code หรือไฟล์ final ก่อนจ่ายครบ
- ไม่มีชื่อจริง ไม่มีบริษัท ไม่มีอีเมลทางการ / ไม่ยอมเซ็นอะไรเลย
- ขอข้อมูล bank / password / OTP หรือให้ออกเงินแทนก่อน
- นายทุนขอหุ้นเยอะ/ขอ control มาก แต่ลงเงินน้อยหรือยังไม่โอนเงิน
- ไม่ระบุว่าเงินลงทุนเป็น “หุ้น เงินกู้ หรือ convertible”
- founder ต้องค้ำหนี้ส่วนตัว

---

## 1. Freelance Service Agreement

- “ทำไปก่อน เดี๋ยวจ่ายทีเดียว”
- “ถ้างานดี เดี๋ยวมีงานใหญ่ตามมา”
- “ขอ source code ก่อน เดี๋ยวโอน”
- ไม่มีชื่อจริง ไม่มีบริษัท ไม่มีอีเมลทางการ
- ไม่ยอมเซ็นอะไรเลย
- เปลี่ยน requirement เรื่อย ๆ แต่ไม่เพิ่มเงิน
- test task ใหญ่เกินไปเหมือนเอางานจริงไปใช้ฟรี

## 2. Outsourcing Service Agreement

- บริษัทใช้คุณเหมือนพนักงาน full-time แต่ไม่ให้สิทธิพนักงาน
- Scope เขียนกว้างเกิน เช่น “ทำงานตามที่บริษัทมอบหมาย”
- support ไม่ระบุเวลาชัด
- ไม่แยก development / maintenance / emergency support
- change request ไม่คิดเงินเพิ่ม

## 3. Independent Contractor Agreement

- ต้องทำงาน full-time 09:00–18:00 แต่เขียนว่าไม่ใช่พนักงาน
- ห้ามทำงานให้ลูกค้าอื่นทั้งหมด
- ไม่มี milestone payment
- บริษัทเป็นเจ้าของงานทันทีตั้งแต่ยังไม่จ่ายครบ
- เลิกสัญญาได้ทันทีโดยไม่ต้องจ่ายงานที่ทำไปแล้ว
- มี penalty ฝั่งคุณฝ่ายเดียว
- non-compete กว้างเกิน เช่น ห้ามทำงานกับบริษัทเกมอื่น 2 ปี

## 4. Fixed-term Employment Contract

- ทำงานเหมือนพนักงานเต็มเวลา แต่ไม่มีสิทธิพนักงาน
- ไม่มีวันลา
- ไม่มีประกันสังคม
- จ้างระยะยาวแต่ต่อสัญญาสั้น ๆ เพื่อเลี่ยงสิทธิ
- เลิกจ้างได้ทันทีโดยไม่มี notice
- หักเงินถ้าลาออกก่อน
- ห้ามทำงานในสายเดียวกันหลังออกจากงาน

## 5. NDA / Confidentiality Agreement

- เขียนว่าทุกอย่างที่คุณคิดได้หลังคุยกับเขาเป็นของเขา
- ห้ามคุณทำงานคล้ายกันตลอดไป
- ไม่มีวันหมดอายุ
- คำว่า confidential information กว้างเกินไป
- penalty สูงมากแบบไม่สมเหตุสมผล
- ใช้ NDA แอบซ่อน non-compete

## 6. MSA + SOW

- MSA เขียน broad มาก แต่ SOW ไม่ชัด
- SOW ไม่มี acceptance criteria
- SOW ไม่บอกว่าอะไรอยู่นอก scope
- ไม่มี change request process
- ไม่มี payment milestone

## 7. Term Sheet

- นายทุนขอหุ้นเยอะมากเมื่อเทียบกับเงิน
- มีสิทธิควบคุมบริษัทมากเกินสัดส่วนหุ้น
- founder เสียอำนาจตัดสินใจทั้งหมด
- มี veto rights กว้างเกินไป
- บังคับ founder ห้ามทำธุรกิจอื่นกว้างเกิน
- ไม่มี timeline ชัดเจน
- ให้ exclusivity นานเกิน ทำให้คุณไปคุยกับคนอื่นไม่ได้

## 8. Shareholders Agreement

- investor ถือหุ้นน้อยแต่ veto ได้ทุกเรื่อง
- founder ไม่มีอำนาจบริหาร
- founder vesting โหดเกิน
- bad leaver กว้างเกิน เช่น แค่ลาออกก็เสียหุ้นทั้งหมด
- drag-along ไม่มีราคาขั้นต่ำ
- ห้าม founder ทำงานสายเดียวกันแบบกว้างเกินไป
- ไม่มีวิธีแก้ deadlock

## 9. Share Subscription Agreement

- นักลงทุนขอสิทธิพิเศษเยอะแต่ไม่ใส่เงินตามกำหนด
- ไม่มี deadline การโอนเงิน
- ไม่บอกว่าจะใช้เงินลงทุนเพื่ออะไร
- founder ต้องรับประกันเรื่องที่ควบคุมไม่ได้
- มีเงื่อนไขให้เรียกเงินคืนง่ายเกินไป

## 10. Convertible Note

- ดอกเบี้ยสูง
- maturity สั้นเกิน
- valuation cap ต่ำเกิน ทำให้เสียหุ้นเยอะ
- investor มีสิทธิเรียกคืนเงินทันที
- founder ค้ำประกันส่วนตัว
- ไม่มีเงื่อนไขชัดว่าแปลงหุ้นเมื่อไหร่

## 11. SAFE

- valuation cap ต่ำเกิน
- ไม่มีความชัดเจนเรื่อง conversion
- founder ไม่เข้าใจ dilution
- มีหลาย SAFE ซ้อนกันจน cap table พัง
- เงื่อนไข liquidation event เอื้อ investor มากเกินไป

## 12. Loan Agreement

- ให้ founder ค้ำส่วนตัวโดยไม่จำเป็น
- ดอกเบี้ยสูง
- มีหลักประกันเกินมูลหนี้
- ผิดนัดนิดเดียวเรียกคืนทั้งหมด
- นักลงทุนได้ทั้งดอกเบี้ยและหุ้นโดยไม่ชัดเจน
- ไม่มี grace period

---

## 🧠 กฎจำง่ายกันพลาด

> **งานรับจ้าง:** Demo ได้ แต่ final source code ต้องหลังรับเงินครบ
> **นายทุน:** หุ้นให้ได้ แต่ control ต้องไม่เสียโดยไม่รู้ตัว
> **เงินลงทุน:** ต้องรู้ก่อนว่าเป็น “หุ้น” หรือ “หนี้”

หมวดที่ red flag โผล่บ่อยสุด → **เงิน / ownership / control / การเลิกสัญญา**
ถ้าเอกสารเงียบเรื่องใดเรื่องหนึ่งใน 4 นี้ = ต้องถามให้ชัดก่อนเซ็น
