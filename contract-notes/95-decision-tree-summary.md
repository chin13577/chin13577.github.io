# Mini Decision Tree + สรุปสั้น

## Mini Decision Tree

### ถ้าเขาบอกว่า “จ้าง contract”

ถามก่อน:

> เป็นพนักงานสัญญาจ้าง หรือ contractor agreement?

ถ้าเขาบอกว่า:

- มีเงินเดือน
- มีเวลาเข้างาน
- มีหัวหน้า
- มีวันลา
- มีประกันสังคม

น่าจะเป็น **Fixed-term Employment Contract**

ถ้าเขาบอกว่า:

- จ่ายตาม milestone
- ส่งงานเป็น deliverable
- ออก invoice
- ไม่มีวันลา
- ไม่มีประกันสังคม
- ทำงานอิสระ

น่าจะเป็น **Independent Contractor / Freelance / Outsource**

---

## สรุปสั้นมาก

ถ้าเป็นงานรับจ้าง:

> ต้องชัด 5 เรื่อง: ทำอะไร / ส่งอะไร / ส่งเมื่อไหร่ / จ่ายยังไง / โอนสิทธิ์เมื่อไหร่

ถ้าเป็น contract employee:

> ต้องชัดเรื่องเงินเดือน / วันลา / ประกันสังคม / notice / OT / ต่อสัญญา

ถ้าเป็น outsource:

> ต้องชัดเรื่อง scope / SLA / support / payment / ownership

ถ้าเป็นนายทุน:

> ต้องชัดว่าเงินเป็นหุ้น เงินกู้ หรือ convertible และใครมีอำนาจตัดสินใจหลังลงทุน

กฎจำง่าย:

> Demo ได้ แต่ final source code ต้องหลังรับเงินครบ
> หุ้นให้ได้ แต่ control ต้องไม่เสียโดยไม่รู้ตัว
> เงินลงทุนต้องรู้ก่อนว่าเป็น “หุ้น” หรือ “หนี้”
