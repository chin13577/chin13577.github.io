# Checklist ก่อนเริ่มงานหรือเซ็นสัญญา

## 10.1 ตรวจตัวตนอีกฝ่าย

- ชื่อจริง / ชื่อบริษัท
- เลขทะเบียนบริษัท
- อีเมลบริษัท
- เว็บไซต์
- LinkedIn / portfolio
- ที่อยู่
- ผู้มีอำนาจเซ็น
- ข้อมูลการจ่ายเงิน
- ประวัติการจ่ายงานกับคนอื่น

## 10.2 ตรวจเรื่องเงิน

- จ่ายเมื่อไหร่
- จ่ายกี่งวด
- จ่ายผ่านอะไร
- มี invoice ไหม
- มี withholding tax ไหม
- ถ้าจ่ายช้า ทำอย่างไร
- ถ้ายกเลิกงาน จ่ายส่วนที่ทำแล้วไหม
- ใครรับค่าธรรมเนียมโอนเงิน
- สกุลเงินอะไร
- exchange rate ใช้วันไหน

## 10.3 ตรวจเรื่องงาน

- Scope ชัดไหม
- Out of Scope ชัดไหม
- Deliverables ชัดไหม
- Timeline ชัดไหม
- Acceptance criteria ชัดไหม
- จำนวนรอบแก้ไขชัดไหม
- change request คิดเงินเพิ่มไหม
- client ต้องส่งข้อมูลอะไรให้เราบ้าง
- ถ้า client delay timeline ขยับไหม

## 10.4 ตรวจเรื่อง source code / IP

- ใครเป็นเจ้าของ source code
- โอนสิทธิ์เมื่อไหร่
- โอนหลังจ่ายครบหรือไม่
- ใช้ reusable code/library ของเราได้ไหม
- เอางานไปใส่ portfolio ได้ไหม
- ห้ามใช้ความรู้ทั่วไปของเราหรือไม่
- มี open-source license อะไรเกี่ยวข้องไหม

## 10.5 ตรวจเรื่องจบงาน

- ยกเลิกได้เมื่อไหร่
- ต้องแจ้งล่วงหน้ากี่วัน
- จ่ายงานที่ทำไปแล้วไหม
- ต้องส่งมอบอะไรเมื่อจบงาน
- ต้องลบข้อมูลลูกค้าไหม
- support หลังส่งงานกี่วัน
- warranty bug fix ครอบคลุมแค่ไหน
