# Freelance Service Agreement

## คืออะไร

สัญญาจ้างฟรีแลนซ์คือสัญญาที่ผู้ว่าจ้างให้คุณทำงานเฉพาะชิ้นหรือเฉพาะโปรเจกต์ โดยคุณไม่ได้เป็นพนักงานของเขา

เหมาะกับ:

- ทำเว็บไซต์
- ทำระบบ backend
- ทำ Unity feature
- ทำ prototype
- ทำ UI/UX
- ทำ design
- ทำ content
- ทำ automation script
- ทำ bug fixing เป็นรอบ

## หัวข้อที่ควรมีในสัญญา

1. คู่สัญญา
2. Scope of Work
3. Deliverables
4. Timeline
5. Payment Terms
6. Milestone
7. Acceptance Criteria
8. Revision / Change Request
9. IP / Source Code Ownership
10. Confidentiality
11. Termination
12. Governing Law

## Payment ที่ปลอดภัย

| ขนาดงาน | วิธีจ่ายที่แนะนำ |
|---|---|
| งานเล็ก ต่ำกว่า 10,000 บาท | 50% ก่อนเริ่ม / 50% ก่อนส่ง final |
| งานกลาง 10,000–100,000 บาท | 40% ก่อนเริ่ม / 30% หลัง demo / 30% ก่อนส่ง source final |
| งานใหญ่ 100,000+ บาท | แบ่ง milestone ราย module / รายสัปดาห์ / รายเดือน |

## จุดกันโดนโกง

- อย่าเริ่มงานเต็มก่อนมีเงินมัดจำ
- อย่าส่ง source code final ก่อนจ่ายครบ
- demo ได้ แต่ final package ต้องหลังปิดเงิน
- ระบุจำนวนรอบแก้ไข
- ระบุว่า “งานนอก scope ต้องคิดเงินเพิ่ม”
- หากลูกค้าหายเกิน X วัน ถือว่างานงวดนั้น accepted
- ถ้ายกเลิกกลางทาง ต้องจ่ายตามงานที่ทำแล้ว

## Red flags

- “ทำไปก่อน เดี๋ยวจ่ายทีเดียว”
- “ถ้างานดี เดี๋ยวมีงานใหญ่ตามมา”
- “ขอ source code ก่อน เดี๋ยวโอน”
- ไม่มีชื่อจริง ไม่มีบริษัท ไม่มีอีเมลทางการ
- ไม่ยอมเซ็นอะไรเลย
- เปลี่ยน requirement เรื่อย ๆ แต่ไม่เพิ่มเงิน
- test task ใหญ่เกินไปเหมือนเอางานจริงไปใช้ฟรี

## ประโยคที่ควรใช้

> เพื่อความชัดเจนของทั้งสองฝ่าย ผมขอเริ่มงานหลังจากยืนยัน scope และชำระงวดแรกตาม milestone นะครับ ส่วน source code หรือไฟล์ final จะส่งมอบหลังจากชำระครบครับ

## ฐานทางกฎหมาย

ในทางกฎหมายไทย งานฟรีแลนซ์ (รับทำงานให้สำเร็จเป็นชิ้น เน้น “ผลสำเร็จของงาน”) จัดเป็น **สัญญาจ้างทำของ** ตามประมวลกฎหมายแพ่งและพาณิชย์ มาตรา 587 ไม่ใช่สัญญาจ้างแรงงาน จึงไม่มีความสัมพันธ์แบบนายจ้าง–ลูกจ้าง และไม่มีสิทธิแรงงาน (ประกันสังคมภาคบังคับ/ค่าชดเชย) ติดมา — แต่ฟรีแลนซ์สามารถสมัครเป็นผู้ประกันตนโดยสมัครใจตาม **มาตรา 40 พ.ร.บ.ประกันสังคม** ได้เอง

### ภาษีของฟรีแลนซ์ (จุดที่คนสรุปผิดบ่อย)

- เงินได้ฟรีแลนซ์อาจเป็นเงินได้ตามประมวลรัษฎากร **มาตรา 40(2)** (ค่าตอบแทนจากการรับทำงานให้) หรือ **มาตรา 40(7)/(8)** (ค่าจ้างทำของ/เงินได้จากธุรกิจ ที่มีต้นทุน เช่น รับเหมาทั้งค่าแรงและสัมภาระ) แล้วแต่ลักษณะงานจริง
- อัตราหัก ณ ที่จ่าย **3%** ที่ฟรีแลนซ์เจอบ่อย มาจากคำสั่งกรมสรรพากร **ท.ป.4/2528** ซึ่งใช้กับ “ค่าจ้างทำของ/ค่าบริการ” ที่เป็นเงินได้ 40(7) หรือ 40(8) เมื่อผู้จ่ายเป็นบริษัท/นิติบุคคล
- ส่วนเงินได้ **40(2)** ที่นิติบุคคลจ่ายให้บุคคลธรรมดา (ผู้อยู่ในไทย) ตามกฎหมายต้องคำนวณหัก ณ ที่จ่าย **ตามอัตราก้าวหน้า** เหมือนเงินเดือน (มาตรา 50(1)) ไม่ใช่ 3% คงที่ — ในทางปฏิบัติอาจหักออกมาได้น้อยกว่าหรือมากกว่า 3% ก็ได้
- ไม่ว่ากรณีไหน ภาษีที่ถูกหักเป็นเพียง “ภาษีจ่ายล่วงหน้า” ต้องนำรายได้ทั้งปีมายื่นภาษีเงินได้บุคคลธรรมดาอีกครั้ง และ **ควรขอหนังสือรับรองหักภาษี ณ ที่จ่าย (50 ทวิ) ทุกครั้ง** เพื่อใช้เครดิตภาษีตอนยื่นประจำปี
