# คู่มือความรู้: ประเภทสัญญาสำหรับ Freelance / Outsource / Contract / นายทุน

> เอกสารชุดนี้ทำไว้เพื่อใช้เป็น “โน้ตเตรียมคุย” และ checklist ก่อนรับงานหรือคุยกับนายทุน
> ไม่ใช่คำปรึกษาทางกฎหมายโดยตรง หากเป็นดีลใหญ่ เงินเยอะ มีหุ้น หรือมีความเสี่ยงสูง ควรให้ทนายตรวจสัญญาก่อนเซ็น

---

## 1. ภาพรวมแบบเข้าใจง่าย

คำว่า “สัญญา” ที่เจอบ่อยในงาน dev / startup / freelance มักมีหลายแบบ และแต่ละแบบมีความเสี่ยงไม่เหมือนกัน

| ประเภท | ใช้เมื่อไหร่ | จุดสำคัญที่สุด | ความเสี่ยงหลัก |
|---|---|---|---|
| Freelance Service Agreement | รับงานเป็นชิ้น/โปรเจกต์เล็ก-กลาง | Scope, Payment, Deliverables | ทำแล้วไม่จ่าย / scope creep |
| Outsourcing Service Agreement | บริษัทจ้างคนนอก/ทีมข้างนอกทำงานต่อเนื่อง | Scope, SLA, Ownership, Confidentiality | โดนใช้เหมือนพนักงานแต่ไม่มีสิทธิ |
| Independent Contractor Agreement | รับงานแบบ contractor ไม่ใช่พนักงาน | สถานะไม่ใช่ลูกจ้าง, payment, IP | ไม่มีสวัสดิการ / จ่ายช้า / ห้ามทำงานอื่น |
| Fixed-term Employment Contract | พนักงานสัญญาจ้าง 3 เดือน / 6 เดือน / 1 ปี | เงินเดือน, วันลา, ประกันสังคม, notice | บริษัทเขียนให้เสียสิทธิแรงงาน |
| NDA | คุยงาน/ดูข้อมูลลับก่อนเริ่มจริง | ห้ามเปิดเผยข้อมูลลับ | เขียนกว้างเกินจนทำงานอื่นไม่ได้ |
| MSA + SOW | งานบริษัท/enterprise หลายเฟส | MSA = กติกาหลัก, SOW = รายละเอียดงานแต่ละเฟส | SOW ไม่ชัด ทำให้โดนเพิ่มงาน |
| Shareholders Agreement | มีผู้ถือหุ้นหลายคน / มีนายทุน | อำนาจ, หุ้น, exit, deadlock | เสีย control บริษัท |
| Term Sheet | สรุปเงื่อนไขก่อนลงทุนจริง | valuation, equity, investment structure | คุยไม่ชัดก่อนทำสัญญาจริง |
| Convertible Note / SAFE | นายทุนให้เงินก่อน แปลงเป็นหุ้นภายหลัง | discount, valuation cap, maturity | founder เสียหุ้นมากกว่าที่คิด |
| Loan Agreement | นายทุนให้เงินแบบเงินกู้ | ดอกเบี้ย, repayment, collateral | หนี้ส่วนตัว / ค้ำประกัน |

## 2. แยกก่อนว่าเป็น “จ้างแรงงาน” หรือ “จ้างทำของ”

### 2.1 จ้างแรงงาน

ลักษณะคือ คุณทำงานให้บริษัทในฐานะลูกจ้าง บริษัทควบคุมเวลาทำงาน วิธีทำงาน สถานที่ทำงาน และจ่ายค่าจ้างเป็นเงินเดือนหรือค่าจ้างประจำ

ตัวอย่าง:

- ต้องเข้างาน 09:00–18:00
- มีหัวหน้างานสั่งงานรายวัน
- ใช้เครื่องมือของบริษัท
- ได้เงินเดือนประจำ
- มีวันลา ประกันสังคม หรือสวัสดิการ
- บริษัทควบคุมวิธีทำงานค่อนข้างมาก

มักใช้กับ:

- Employment Contract
- Fixed-term Employment Contract
- Contract Employee

### 2.2 จ้างทำของ

ลักษณะคือ คุณรับทำงานให้สำเร็จเป็นชิ้นงานหรือผลลัพธ์ เช่น feature, website, app, module, source code, design file

ตัวอย่าง:

- จ่ายตาม milestone
- มี deliverable ชัดเจน
- คุณเลือกวิธีทำงานเองได้
- ไม่จำเป็นต้องเข้างานตามเวลาบริษัท
- ลูกค้าสนใจผลลัพธ์มากกว่าวิธีทำงาน
- ส่งมอบงานแล้วตรวจรับ

มักใช้กับ:

- Freelance Agreement
- Outsourcing Agreement
- Independent Contractor Agreement
- Service Agreement
