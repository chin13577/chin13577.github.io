# วิธีส่งงานให้ปลอดภัย

## ระหว่างงาน

- ส่ง demo build
- ส่ง video demo
- ส่ง screenshot
- ส่ง staging URL
- ส่ง partial build
- ใช้ watermark ใน design preview
- ไม่ส่ง credential production
- ไม่ส่ง source code full repo ก่อนเงินครบ

## ก่อนรับเงินครบ

ทำได้:

- demo call
- binary build
- test server
- compiled package
- read-only review
- limited access

ไม่ควรทำ:

- ส่ง Git repo ทั้งหมด
- ส่ง production credential
- โอน domain
- โอน app store account
- ส่ง private key
- ส่ง database dump จริง
- ส่ง asset ต้นฉบับทั้งหมด

## หลังรับเงินครบ

ค่อยส่ง:

- source code
- final files
- documentation
- production credential ที่จำเป็น
- deployment package
- transfer ownership
- handover note
