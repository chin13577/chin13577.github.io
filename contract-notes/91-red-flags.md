# Red Flags รวมที่ควรระวังมาก

## ฝั่งงาน freelance / outsource / contractor

- ไม่ยอมจ่ายมัดจำ
- ให้ทำงานก่อนโดยไม่มีเอกสาร
- ขอ source code ก่อนจ่ายครบ
- scope กว้างเกิน
- แก้งานไม่จำกัด
- requirement เปลี่ยนเรื่อย ๆ
- ไม่มี acceptance criteria
- จ่ายหลังงานเสร็จทั้งหมดเท่านั้น
- penalty ฝั่งคุณฝ่ายเดียว
- non-compete กว้างเกิน
- ห้ามรับงานอื่นโดยไม่จ่าย full-time rate
- ให้ใช้บัญชีส่วนตัวหรือ personal credential
- ลูกค้าขอให้คุณออกเงินก่อน
- ลูกค้าขอข้อมูล bank/password/OTP

## ฝั่งนายทุน

- ขอหุ้นเยอะมากแต่ลงเงินน้อย
- ขอ control มากกว่าสัดส่วนหุ้น
- ขอเป็นกรรมการผู้มีอำนาจเซ็นคนเดียว
- ขอ veto ทุกเรื่อง
- ให้ founder ค้ำหนี้ส่วนตัว
- ไม่โอนเงินแต่ขอเริ่มใช้สิทธิในบริษัท
- ขอ exclusivity นานเกินไป
- สัญญาเขียนให้นักลงทุนถอนเงินคืนได้ง่าย แต่ founder ถอนตัวไม่ได้
- ไม่มีเงื่อนไขชัดเจนว่าเงินเข้าบริษัทเมื่อไหร่
- ไม่ระบุว่าเงินลงทุนเป็นหุ้น เงินกู้ หรือ convertible
