# Convertible Note

## คืออะไร

Convertible Note คือเงินกู้ที่ภายหลังสามารถแปลงเป็นหุ้นได้

เหมาะกับช่วงที่ยังตกลง valuation ยาก หรือบริษัทอยู่ early stage

## คำสำคัญ

| คำ | ความหมาย |
|---|---|
| Principal | เงินต้นที่นักลงทุนให้ |
| Interest | ดอกเบี้ย |
| Maturity Date | วันครบกำหนด |
| Conversion | การแปลงหนี้เป็นหุ้น |
| Discount | ส่วนลดตอนแปลงเป็นหุ้น |
| Valuation Cap | เพดาน valuation ที่ใช้ตอนแปลง |
| Qualified Financing | รอบลงทุนที่ trigger ให้แปลงหุ้น |

## Red flags

- ดอกเบี้ยสูง
- maturity สั้นเกิน
- valuation cap ต่ำเกิน ทำให้เสียหุ้นเยอะ
- investor มีสิทธิเรียกคืนเงินทันที
- founder ค้ำประกันส่วนตัว
- ไม่มีเงื่อนไขชัดว่าแปลงหุ้นเมื่อไหร่

---

## ฐานทางกฎหมาย / ข้อจำกัดในไทย

Convertible Note คือ **ตราสารหนี้ระยะสั้นที่แปลงเป็นหุ้นได้** โดยองค์ประกอบมาตรฐานคือ เงินต้น + ดอกเบี้ย + maturity date + เงื่อนไขการแปลง (มักแปลงอัตโนมัติเมื่อเกิด Qualified Financing โดยใช้ discount หรือ valuation cap แล้วแต่ค่าไหนให้ราคาต่อหุ้นต่ำกว่า)

⚠️ ข้อจำกัดสำคัญของบริษัทจำกัดไทย: **ป.พ.พ. มาตรา 1229 ห้ามบริษัทจำกัดออก “หุ้นกู้”** (หุ้นกู้ออกได้เฉพาะบริษัทมหาชนตามกฎหมายหลักทรัพย์) ดังนั้นดีล convertible note ของ startup ไทยที่เป็นบริษัทจำกัด ในทางปฏิบัติมักทำเป็น **สัญญากู้ยืมเงินที่มีข้อตกลงให้สิทธิแปลงหนี้เป็นทุน** (convertible loan agreement) และตอนแปลงจริงต้องผ่านขั้นตอนเพิ่มทุนตามกฎหมาย (มติพิเศษ + จดทะเบียน — ดูไฟล์ [09](09-share-subscription-agreement.md)) เพราะเป็นเงินกู้ ข้อกฎหมายเรื่องหลักฐานการกู้และเพดานดอกเบี้ย 15% ต่อปี จึงใช้ด้วย (ดูไฟล์ [12](12-loan-agreement.md))
