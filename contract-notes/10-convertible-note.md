# Convertible Note

## คืออะไร

Convertible Note คือเงินกู้ที่ภายหลังสามารถแปลงเป็นหุ้นได้

เหมาะกับช่วงที่ยังตกลง valuation ยาก หรือบริษัทอยู่ early stage

## คำสำคัญ

| คำ | ความหมาย |
|---|---|
| Principal | เงินต้นที่นักลงทุนให้ |
| Interest | ดอกเบี้ย |
| Maturity Date | วันครบกำหนด |
| Conversion | การแปลงหนี้เป็นหุ้น |
| Discount | ส่วนลดตอนแปลงเป็นหุ้น |
| Valuation Cap | เพดาน valuation ที่ใช้ตอนแปลง |
| Qualified Financing | รอบลงทุนที่ trigger ให้แปลงหุ้น |

## Red flags

- ดอกเบี้ยสูง
- maturity สั้นเกิน
- valuation cap ต่ำเกิน ทำให้เสียหุ้นเยอะ
- investor มีสิทธิเรียกคืนเงินทันที
- founder ค้ำประกันส่วนตัว
- ไม่มีเงื่อนไขชัดว่าแปลงหุ้นเมื่อไหร่
