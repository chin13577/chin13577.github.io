Overview

Client = Unity (senior 1 + mid 1) · Backend บน PlayFab (CloudScript / Azure Functions) · ตัวเลขเป็น dev MD ไม่รวม art, game design, content, QA เฉพาะทาง

🅰️ Plan A — PlayFab-only

ทีม 3 คน · client 2 + PlayFab dev 1 (backend 1 คน)
  • Dev MD รวม ~324 MD
  • + QA / Integration / Polish (~30%) ~420 MD
  • Timeline (คอขวด backend 1 คน) ~8–9 เดือน
  • ความเสี่ยง Bus factor สูง

🅱️ Plan B — PlayFab + Mid Backend

ทีม 4 คน · client 2 + backend 2 (PlayFab dev + mid backend ทำ custom)
  • Dev MD รวม ~402 MD
  • + QA / Integration / Polish (~30%) ~520 MD
  • Timeline (backend ขนานกันได้) ~7–7.5 เดือน
  • ได้เพิ่ม Realtime chat · Anti-cheat · Scale
💡 Plan B ใช้ MD มากกว่า แต่เสร็จเร็วกว่า — เพราะ Plan A ติดคอขวดที่ backend คนเดียว (166 MD) ส่วน Plan B เติมคนตรงกองงานที่ช้าที่สุดพอดี
